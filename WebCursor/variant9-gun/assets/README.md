# 音效說明

已經放好你上傳的 `shot.mp3`(開火音效)跟 `reload.mp3`(換彈音效),
`script.js` 裡的 `SHOT_SOUND_SRC` / `RELOAD_SOUND_SRC` 對應這兩個檔案,
不用再手動處理。想換成別的檔案的話,直接改這兩個常數指到你要的路徑即可。

## 這個資料夾裡已經放好的素材

- `gun.gif`:你上傳的原始動畫(768x384,10 幀,每幀 100ms,共 1 秒)。
- `gun_frame1.png`:從 `gun.gif` 抽出來的第一幀,平常(未開火)顯示這張靜態圖,
  開火瞬間才切換成 `gun.gif` 播放動畫,播完自動切回這張。
- `ammo.png`:你上傳的子彈圖示,右下角堆疊用。
- `shot.mp3`:開火音效。
- `reload.mp3`:換彈音效(彈藥歸零、開始等待 2 秒時播放)。
